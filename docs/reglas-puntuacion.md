# Reglas de puntuación (punto de partida, a calibrar)

Datos de Open-Meteo por hora: nubes bajas, medias y altas, probabilidad de lluvia, visibilidad. Se miran las horas desde 1 h antes de la puesta hasta 30 min después.

## Atardecer

**Vetos (rojo directo):** nubes bajas > 60 %; lluvia probable (> 50 %) en la hora de la puesta.

| Factor | Rango | Puntos |
|---|---|---|
| Nubes bajas | < 20 % | 40 |
| | 20-40 % | 20 |
| | 40-60 % | 5 |
| Nubes medias y altas | 20-70 % | 40 |
| | 10-20 % o 70-85 % | 20 |
| | < 10 % o > 85 % | 5 |
| Visibilidad | > 15 km | 20 |
| | 5-15 km | 10 |
| | < 5 km | 0 (aviso de niebla) |

Semáforo: 70-100 verde ("Prometedor"); 40-69 ámbar ("Posible, pero incierto"); 0-39 rojo ("Poco probable"). Siempre con el porqué y la hora de actualización.

Niebla (poca visibilidad y humedad alta): "Atardecer: no. Niebla en la ría: puede merecer la pena".

## Luna
Nubes totales a la hora en que la luna está alta, y lluvia:
- < 30 %: verde ("Se verá bien")
- 30-60 %: ámbar ("Posible entre nubes")
- > 60 % o lluvia: rojo ("Poco probable")

La fase no baja la nota; cambia el consejo (llena = plana; cuartos = relieve).

## Límites conocidos
- La previsión no ve el horizonte: nunca decir "seguro".
- Mejora v2: consultar un segundo punto a 30-50 km en dirección a la puesta.
- Calibrar umbrales con un diario de salidas.
